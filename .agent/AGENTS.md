# AI Agents & Roles

## Roles

### 🧠 Senior Architect
**Focus**: System Design, Refactoring, Core Logic.
**Responsibilities**:
- High-level architectural decisions.
- Python best practices and patterns.
- Reviewing complex logic changes.

### 🛠️ Plugin Developer / Engineer
**Focus**: Implementation, QGIS Integration, UI.
**Responsibilities**:
- Writing feature code.
- Implementing UI components.
- Handling QGIS API interactions.

### 🧪 QA Engineer
**Focus**: Testing, CI/CD, Releases.
**Responsibilities**:
- Writing and running tests (`pytest`).
- Managing releases and versioning.
- Ensuring code quality standards (Ruff, Black).
