# Release Notes - v3.5.0 (Explainable Scoring & Context Enrichment)

This version focuses on **correctness of the generated reports**, **explainability of the
Quality Score**, and **richer context** for AI-assisted workflows, plus a clear
deprecation path toward v4.0.0.

## Highlights

### 🎯 Correctness
- **Entry Points fixed**: the `ENTRY POINTS` section was always empty because the computed
  list was never persisted. It now shows each entry point with its type
  (`qgis_plugin`, `main_guard`, `click_cli`, ...).
- **Test counting decoupled from `.analyzerignore`**: excluding `tests/` no longer forces a
  false `-20` penalty. The metric is renamed to **Test Files** and unknown counts render `n/a`.

### 📊 Explainable, Configurable Score
- `PROJECT_SUMMARY.md` now includes an explicit **Score Breakdown**
  (base, average complexity, max complexity, maintainability, tests).
- The score also penalizes **max-complexity outliers**, so per-function gates are surfaced.
- All thresholds and weights live in a `[scoring]` config section and can be tuned per project.

### 🧩 Richer Context
- **`--include-md <glob>`** (repeatable) and the `context_docs` config key embed extra
  architecture docs (`ARCHITECTURE.md`, `docs/**`) into the "MANUAL ARCHITECTURE NOTES" section.
- **i18n UI allowlist**: strings passed to user-facing setters (`setText`, `setTitle`, ...)
  are counted even when the generic heuristics would reject them; the ignore/allow lists are
  configurable via `patterns.i18n`.

### 🗑️ Deprecations (removal in v4.0.0)
- Legacy compatibility facades (`patterns_detectors`, `context_builders`, `commands`,
  `cli_groups`) and the `ContextAggregator` / `QGISComplianceVisitor` aliases now emit
  `DeprecationWarning`. See the README "API Stability and Deprecations" section.

## ⚠️ Upgrade Notes
- Projects with a module above **CC 25** may see a **lower** `ai-ctx Quality Score` due to the
  new outlier penalty. Review your `audit --threshold` gate accordingly.

## Internal
- Split monolithic modules below the CC budget; added deterministic golden-report fixtures
  and a self-score regression guard; scoped the repository's own analysis via `.analyzerignore`.
