# Release Notes - v3.1.1

## QGIS Profile & Analysis Fixes

This release focuses on resolving critical bugs in the QGIS compliance command and ensuring the architectural facade remains stable after recent modularization.

### Fixed
- **QGIS Profile Enforcement**: The `ai-ctx qgis` command now correctly loads the `qgis` profile by default, ensuring all specialized checks are active and reporting accurate compliance scores.
- **Facade Stability**: Restored missing re-exports in `fs_utils.py`, `issues.py`, `patterns.py`, and `git_analysis.py`. These regressions were causing `AttributeError` and test failures after the extreme fragmentation phase.
- **i18n Detection**: Refined translatable string heuristics to be more resilient to test data and short strings.

### Added
- **Integration Tests**: New test suite in `tests/test_qgis_command.py` verifying the full end-to-end flow of the QGIS compliance command.

### Quality Metrics
- **Audit Score**: 90.9/100
- **Test Coverage**: All 77 tests passing.
