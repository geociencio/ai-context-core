# v3.2.0 - Scoped i18n & TOML Standardization

This release introduces significant improvements to the QGIS analysis precision and standardizes the project's configuration system using TOML.

## Key Changes

### 🔍 Scoped i18n Analysis (QGIS)
- **Granular Control**: New `[qgis.i18n]` configuration to filter translation analysis by path.
- **Predefined Scopes**:
    - `all`: Full project analysis (default).
    - `gui_only`: Focuses exclusively on folders like `gui/`, `dialogs/`, and `widgets/`.
    - `custom`: Allows defining specific inclusion/exclusion glob patterns.
- **CLI Enhancement**: Use `--i18n-scope [all|gui_only|custom]` to override settings during execution.

### ⚙️ TOML Standardization
- **TOML-First**: The project now primarily uses TOML for defaults (`defaults.toml`) and profiles (`profiles/*.toml`).
- **Legacy Compatibility**: Maintains support for existing `.yaml` configurations while prioritizing TOML.
*   **Init Update**: `ai-ctx init` now generates `.toml` configuration profiles by default.

### 🏗️ Architectural Maintenance
- **Facade Elimination**: Finalized the removal of legacy import facades, fully embracing the modular internal structure.
- **Quality Excellence**: Achieved a record **98.4 Quality Score** on the project's own codebase.
