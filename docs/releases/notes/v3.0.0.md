# v3.0.0 - CLI Expansion & Enhanced Analysis

## 🎉 Major Release: 14 CLI Commands

This release marks a significant expansion of `ai-context-core` with **5 new CLI commands** and comprehensive documentation updates, bringing the total to **14 commands** for complete project analysis.

## ✨ New Features

### New CLI Commands

#### 1. `ai-ctx deps` - Dependency Analysis
Comprehensive dependency analysis with three modes:
- `--unused`: Identifies all unused imports across the project
- `--cycles`: Detects circular dependencies that harm maintainability
- `--metrics`: Shows coupling metrics (CBO, graph density, DAG validation)

```bash
ai-ctx deps --unused
ai-ctx deps --cycles  
ai-ctx deps --metrics
ai-ctx deps  # Shows everything
```

#### 2. `ai-ctx git` - Git Evolution Tracking
Analyze code evolution patterns:
- **Hotspots**: Most frequently modified files (refactoring priorities)
- **Code Churn**: Lines added/deleted over configurable time periods

```bash
ai-ctx git --days 30
```

#### 3. `ai-ctx stats` - Quick Statistics
Instant project overview with formatted tables:
- Source Lines (SLOC) vs Physical Lines
- Module, Function, and Class counts
- Average Complexity and Maintenance Index
- Quality Score
- Top 5 most complex modules

```bash
ai-ctx stats
```

#### 4. `ai-ctx qgis` - QGIS Plugin Validation
Specialized compliance checks for QGIS plugin developers:
- `metadata.txt` validation against QGIS.org standards
- Internationalization (i18n) coverage with `self.tr()`
- Qt6/QGIS 4 transition readiness (PyQt5 vs PyQt6 imports)
- Processing Framework usage detection
- Overall QGIS Compliance Score

```bash
ai-ctx qgis
```

#### 5. `ai-ctx clean` - Maintenance Utility
Clean up generated artifacts and cache:
- `.ai_context_cache.json`
- `AI_CONTEXT.md`, `project_context.json`
- `PROJECT_SUMMARY.md/html`

```bash
ai-ctx clean --dry-run  # Preview
ai-ctx clean            # Execute
```
