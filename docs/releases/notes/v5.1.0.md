# Release Notes - v5.1.0 (Context Alignment & Hardening)

Backward-compatible hardening release that aligns the project's own surfaces with
the v5.0.0 context-only contract and makes the flagship artifact token-efficient by
default. No command or artifact contract is removed.

## Highlights

### Token-efficient context by default
- New `[context].mermaid_style` (default `false`): the dependency diagram drops the
  `classDef`/`class … module;` styling block, which dominated the artifact.
- New default budget in `config/defaults.toml`: `max_tokens = 8000` and
  `[context.budget.sections] dependencies = 2500`.
- Measured on this repo: `AI_CONTEXT.md` **2680 → 2056** tokens (-23%);
  `dependencies` **2047 → 1423** (-30%).

### Contract fidelity
- `project_context.json` no longer advertises the retired `security`,
  `qgis_compliance`, `patterns` and `antipatterns` keys (builtin and external
  sources) — those domains are owned by `qgis-plugin-analyzer`.

### Analyzer correctness
- The unused-import detector now honors `# noqa` / `# noqa: F401` (tokenize-based
  line mapping in `visitors/noqa.py`), so intentional re-export/registration
  imports are no longer misreported.

### Documentation & scaffolds
- `docs/ARCHITECTURE.md` and `docs/CONFIGURATION.md` rewritten for the v5 pipeline;
  removed the retired `[security_patterns]` and `[patterns.i18n]` sections.
- `ai-ctx init` no longer scaffolds stale v4 workflows; it points to the
  agentic-forge framework (`.agent/`).
- `AGENTS.md` and overlay skills aligned with the context-only contract; added a
  project release overlay skill and an agentic-forge improvement proposal.
