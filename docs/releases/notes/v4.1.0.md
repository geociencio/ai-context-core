# Release Notes - v4.1.0 (Context Map & Debt Prioritization)

This is a **minor version** that turns the analyzer into a real context map with
actionable debt prioritization. It repairs the import graph and dependency
diagram, computes realistic per-file churn, surfaces anti-pattern severity, adds
a context-only mode, and makes `AI_CONTEXT.md` sections configurable.

## Highlights

### 🔗 Import graph & dependency diagram repaired
- Imports carrying a distribution package prefix (e.g. `sec_interp.core.x` vs a
  flat `core/` layout) now resolve correctly, as do **relative imports**
  (`from . import x`).
- The Mermaid diagram is rewritten: collision-free node IDs, `class` declared for
  every cited node, and no more `--> py` artifacts. The self-analysis import
  graph grew from 28 to 45 edges.

### 📈 Realistic churn & hotspots
- Churn now uses `git log --numstat --find-renames` and is grouped **per file**,
  so renames no longer inflate the total (the previous global shortstat sum could
  report absurd totals like `512,593`).
- `AI_CONTEXT.md` now shows a **top-5 churned files** list, cross-referenced with
  hotspots.

### ⚠️ Anti-pattern severity & allowlist
- Magic-number detection now honors a configurable `allowlist` (defaults exempt
  common constants like `100`, `1000`, `1024`, `3600`, …).
- Anti-patterns are sorted by severity (high → low), rendered with a `[severity]`
  label, and filtered by a configurable `min_severity` cutoff
  (`[patterns.antipatterns]`).

### 🧭 Context-only mode
- New `ai-ctx context` command generates `AI_CONTEXT.md` + `project_context.json`
  **without** emitting or auditing the score.
- `ai-ctx analyze` labels its score output as **heuristic**; `ai-ctx audit`
  remains the only score gate.

### 🧩 Configurable AI_CONTEXT sections
- `[context].sections` toggles which sections are rendered (`structure`,
  `metrics`, `patterns`, `dependencies`, `git`, `qgis`).
- The low-value `PROJECT KEYWORDS` section is dropped, and `__future__` imports
  are no longer flagged as unused.

## Internal
- Unified configuration loading into a single canonical
  `providers.config_loader.load_config` (TOML preferred, YAML legacy fallback);
  `config.loader.ConfigLoader` is now a `DeprecationWarning` facade.
- `sync_metrics.py` now emits the framework-compatible `summary`/`last_session`
  schema expected by `forge metrics validate`.
