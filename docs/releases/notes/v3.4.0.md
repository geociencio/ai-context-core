# Release Notes - v3.4.0 (Corrections & Agentic System Gen 8)

This version consolidates the analyzer's correctness and hygiene improvements, and migrates the agentic development system to the opencode-native Generation 8 architecture.

## Major Changes

### 🌍 i18n Precision
- **`# no-i18n` opt-out**: Developers can now annotate strings with an inline `# no-i18n` comment to exclude them from translation counting.
- **Punctuation heuristic**: Punctuation-dominated strings are no longer flagged as translatable, reducing false positives.

### 🔑 Single Metric Contract
- Project metrics now use canonical keys defined in `builders/metric_keys.py`, eliminating silent `0` fallbacks caused by key mismatches.
- Added `missing_metric_keys` validation that warns when expected keys are absent.

### 📊 Metric Clarity
- User-facing labels renamed to **`ai-ctx Quality Score`** and **`Avg Cyclomatic Complexity`** to avoid confusion with external canonical metrics (e.g. `qgis-analyzer`).
- Added a "Metrics" section to the README defining each metric (average vs gate, heuristic vs canonical).

### 🛡️ Hardening
- Observer signal detection now matches `pyqtSignal`/`Signal` exactly (no substring false positives).
- Safe `.get()` access across pattern/report builders to prevent `KeyError`.

### 🤖 Agentic System Generation 8
- Root `AGENTS.md` as the single source of truth; native subagents (`@architect`, `@qa_engineer`, `@auditor`) in `opencode.json`.
- Retired `skill_sync.py` in favor of `validate_agent_system.py`, `memory_prune.py`, and `sync_metrics.py`.
- 3-tier memory model, 14 English skills, and 11 workflows.

## Technical Improvements
- Added regression tests for metric contract, i18n opt-out, pattern missing keys, and recursive `**` path matching.
- 286 tests passing, ruff clean, agent system validation PASS.
