# Release Notes - v4.0.0 (Dead Code Removal & Metric Key Contract)

This is a **major version** that removes deprecated facades and dead checker
infrastructure, restores architectural purity in the analyzer, and enforces the
canonical metric key contract across all consumers. No new runtime behavior was
added beyond surfacing anti-pattern detections that were previously computed but
never reported.

## Highlights

### 🐛 Anti-patterns now visible
- Detections for **God Object**, **Spaghetti Code**, **Magic Numbers**, and
  **Dead Code** were running on every module but never surfaced. They are now
  aggregated at the project level and rendered in `AI_CONTEXT.md` under a
  `⚠️ DETECTED ANTI-PATTERNS` section.

### 🗑️ Dead code removed (Breaking)
- Removed the dead `CheckerRegistry` chain: `visitors/checker_registry.py`,
  `visitors/security_checker.py`, `visitors/tech_debt_checker.py`, and
  `visitors/debt.py`.
- Removed the deprecated `analyzer/pattern_base.py` facade and unused symbols in
  `visitors/issues.py` (`run_analysis`, `find_security_issues`,
  `GenericIssueDetector`, `detect_ast_security_issues`) and `analyzer/registry.py`
  (`register_visitor`, `register_post_processor`, `get_checker_registry`).

### 🔀 Architecture purity
- `secrets_scanner.py` (the only file-I/O module in `visitors/`) moved to
  `providers/`, keeping AST visitors free of side effects.

### 🔑 Metric key contract enforced
- `stats`, `analyze`, `ai_recommendations`, `context_metrics`, and
  `summary_generator` now read project metrics via `metric_keys` constants; the
  complexity aggregation keys are canonicalized in `formatter.py`.

## ⚠️ Upgrade Notes (Breaking)
- Import paths for the removed facades no longer exist:
  - `ai_context_core.analyzer.pattern_base` → use
    `ai_context_core.analyzer.visitors.pattern_base`.
  - `ai_context_core.analyzer.visitors.security_checker` /
    `tech_debt_checker` / `checker_registry` / `debt` → removed; use the
    canonical AST security detectors and `find_optimizations`.

## Internal
- Removed the `# noqa: F401` re-export hop between `observer_rules.py` and
  `observer_signal_rules.py`; dropped dead legacy wrappers in `singleton_rules.py`.
- Enforced `ruff format` across the repository (fixed a ~80-file version drift).
