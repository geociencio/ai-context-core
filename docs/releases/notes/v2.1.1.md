# Release Notes - v2.1.1 (2026-01-26) - Major Architectural Upgrade & Advanced CLI

## 🚀 Major Architectural Upgrade

This release marks the most significant evolution of `ai-context-core` since its inception. We have transitioned from a monolithic, procedural codebase to a fully modular, class-based architecture.

### Key Highlights:

#### 🏛️ Modular Architecture
- **OOP Refactor**: All core components (Analyzer, CLI, Config, Reporting) are now class-based, enabling better maintainability and testability.
- **Decoupled Engine**: The `ProjectAnalyzer` now orchestrates specialized modules for patterns, metrics, security, and more.

#### 🧠 Intelligent Analysis
- **Design Pattern Detection**: Native support for detecting **Strategy**, **Singleton**, **Observer**, **Factory**, and **Decorator** patterns with confidence scoring.
- **AI Recommendations**: A new heuristic engine that provides actionable advice on code quality and technical debt.
- **Advanced Metrics**: Integrated **Maintenance Index (MI)** and **CBO (Coupling Between Objects)** for deeper code quality insights.

#### 🛡️ Security & Quality
- **AST-based Security**: Advanced detection of SQL Injections (aware of f-strings and formatters) and Secerts scanning with false-positive filtering.
- **Anti-Pattern Detection**: Identifies God Objects, Spaghetti Code, Magic Numbers, and Dead Code.
- **100% Stability**: All refactorings are backed by an extensive test suite (65+ tests) with **77% coverage**.

#### 🛠️ Advanced Command Line
- **Extensible CLI**: Introduces 6 new subcommands for specialized tasks:
    - `inspect`: Deep analysis of a single file.
    - `serve`: Instantly view the interactive report in your browser.
    - `audit`: Score-based pass/fail utility perfect for CI/CD pipelines.
    - `patterns`: Dedicated view for detected design patterns.
    - `security`: Focused security-only scan for vulnerabilities.
    - `help-me`: Quick access to prioritized AI quality recommendations.

#### ⚡ Performance & Workflow
- **Incremental Cache**: Analysis speed increased by **~68%** using SHA-256 based file caching. Use `--no-cache` to force a full re-analysis.
- **Single-Pass Scanning**: Optimized project crawler reducing I/O operations.
- **Docker Native**: Full integration with Docker for consistent development and testing environments.

#### 📊 Enhanced Reporting
- **Interactive HTML**: New interactive reports with **Mermaid.js** dependency diagrams.
- **Standardized Context**: Improved `AI_CONTEXT.md` generation for better LLM alignment.
