# Release Notes v2.5.1 - Bugfix Edition

Esta versión corrige un fallo crítico introducido en la v2.5.0 relacionado con el acceso a metadatos de patrones de diseño.

## 🐛 Fixes
- **KeyError 'class'**: Se corrigió un error que provocaba el cierre inesperado de `ai-ctx analyze` al encontrar decoradores o funciones a nivel de módulo que no definen una clase. Ahora el generador de reportes utiliza métodos de acceso seguros con fallbacks.

## 📊 Impacto
- Estabilidad mejorada en proyectos con uso intensivo de decoradores (`@wraps`, etc.).
- Reportes generados correctamente sin interrupciones.
