# Release Notes - v5.0.1 (Post-Release Cleanup)

Patch release following the `v5.0.0` context-only contract. This is an internal
consolidation and hygiene release: no command or artifact contract changed.

## Highlights

### Single render path
- `ai-ctx analyze` now runs `compile_context -> render_context` for **every**
  source (builtin and external). The separate legacy engine render
  (`ProjectAnalyzer.analyze()` / `_generate_outputs()`) and the dead HTML
  branches were removed, so all artifacts share one provenance/schema path.
- `ai-ctx analyze --format` is `markdown|json`.

### Removed residue
- `ContextAggregator` compatibility alias and the `deprecations` module (the
  removal window had elapsed), `graph_engine`, an unused `maintenance_group`,
  the duplicate calculator Halstead helpers, the `extra_data` parameter, unused
  `get_category` methods and the `SummaryGenerator` alias.

### Repository hygiene
- Removed an orphan `test_project/` fixture and root scratch/cruft
  (`base.json`, `test_analysis.json`, `current_metrics.json`, `full_analysis.md`,
  `report.md`, `test_strategy.py`, `audit_quality.py`, `check_docs.py`).
- Extracted a shared `cli/console.py` (optional-`rich` fallback).

### Robustness & metadata
- `sloc_helpers` uses `ast.Constant` (no more `ast.Str` `DeprecationWarning`).
- `pyproject.toml`: description updated to the context-compiler identity;
  Development Status raised to Production/Stable.
