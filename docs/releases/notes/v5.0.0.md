# Release Notes - v5.0.0 (Context-Only Contract)

This is a **major, breaking release**. `ai-context-core` becomes a **context
compiler** (`source -> transform -> render -> verify`): it *consumes* analysis
instead of owning it. QGIS compliance, i18n, security scanning and quality gates
now live in `qgis-plugin-analyzer`; scaffolding in `agentic-forge`. See
[ADR-0008](../../adr/0008-context-only-contract.md).

## Highlights

### Pluggable sources
- `ai-ctx context --source auto|external|builtin`. `external` consumes
  `qgis-plugin-analyzer` output (`analysis_results/project_context.json`);
  `builtin` runs the retained internal AST engine. `auto` prefers external when
  present.
- Hybrid model: the structure tree, git evolution and manual notes are always
  computed by `ai-context-core`; only the analysis fields come from the source.
- Every artifact carries a `_meta` block (`source`, `schema`, `tool_version`,
  `git_sha`, `content_hash`).

### Token budget and manifest
- `ai-ctx context --max-tokens N` caps `AI_CONTEXT.md` with **deterministic**
  truncation; per-section caps via `[context.budget]`.
- `context_manifest.json` records exact per-section token deltas, the budget and
  the total (`total == header + sum(sections)`).

### Verify, symbol index and health
- `ai-ctx verify` exits `1` when tracked sources changed since the last render
  (content hash); `ai-ctx context --check` gates CI.
- `ai-ctx symbols [--grep]` writes a versioned `symbols.json` (definitions and
  references with `file:line`).
- `ai-ctx health` reports freshness, tokens, symbol coverage and provenance. It
  has **no quality gate**; it fails only on staleness.

### Removed (breaking)
- **Commands**: `audit`, `inspect`, `qgis`, `security`, `patterns`, `full-scan`,
  `fix`, `scaffold`, `doctor`, `interactive`, `serve`. Hidden redirect stubs
  remain for one cycle (they print where the capability moved and exit 0).
- **Analysis domains**: security, QGIS/i18n compliance, design patterns,
  anti-patterns; the `qgis` profile. `PROJECT_SUMMARY` is markdown-only and
  entry-point detection is the `__main__` guard.
- The deprecated `ConfigLoader` facade was removed.

### Internal cleanup (no user-facing API change)
- Single source of truth for metric aggregates, unused-imports, git access and
  git rendering; removed dead modules (`context/manager.py` and
  `context/components/*`, unused constants/config); performance fixes (content
  hash reuses the analysis scan).
- Read-only commands (`stats`, `deps`, `roadmap`, `graph`) no longer write
  artifacts.

## Migration
- Replace `ai-ctx audit` / `ai-ctx qgis` with `qgis-plugin-analyzer` gates, and
  use `ai-ctx context` for context artifacts.
- `ai-ctx audit`-style CI gates: use `ai-ctx context --check` / `ai-ctx verify`.
- The `qgis` config profile moved to `qgis-plugin-analyzer`; `python-generic`
  remains the default here.
