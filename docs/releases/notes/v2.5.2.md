# v2.5.2 - Bugfix Real Release

This release corrects the issue in v2.5.1 where the actual source code fix for the reporting crash was not properly included in the package.

## Fixed
- **KeyError 'class'**: Fixed a critical crash in `SummaryGenerator` and `AICtxGenerator` when processing patterns without a class name. Added safe `.get()` access with fallbacks to module names.
- **Detector Consistency**: Updated `DecoratorDetector` to use the standard `'class'` key for its results, matching other detectors.
