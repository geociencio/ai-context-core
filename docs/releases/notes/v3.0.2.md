# Release Notes - v3.0.2

This maintenance release (v3.0.2) addresses critical bugs discovered in the analysis engine and prepares the codebase for Python 3.14.

## Key Improvements

### 🐍 Python 3.14 Compatibility
Resolved a critical crash in the SLOC engine. Python 3.14 removed `ast.Str` (deprecated since Python 3.8); the analyzer now uses `ast.Constant` as a safe fallback.

### 🎯 Metric Accuracy
- **Complexity Fix**: Resolved a bug in the `ComplexityVisitor` that double-counted logic inside `try` and `async with` blocks. Cyclomatic complexity metrics are now more precise.
- **i18n Scoring**: Significant improvements to QGIS localization analysis.
    - Docstrings are now excluded from the total string count.
    - Heuristics added to ignore non-translatable internal keys.
    - Result: No more "impossible to achieve 100%" scenarios for well-translated plugins.

### 🛡️ Robustness
- **Ignore Filter**: Improved directory exclusion logic. The analyzer now recursively checks path segments, ensuring that files inside ignored directories (like `build/` or `.venv/`) are correctly excluded regardless of the traversal mode.
- **Error Handling**: Fixed a `KeyError` when detecting `QCoreApplication.translate` calls.
