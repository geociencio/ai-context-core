# Release Notes - v3.2.1

## Internationalization & Performance Peak

This release focuses on correcting critical issues in the i18n scoping logic for QGIS plugins and improving overall performance and modularity.

### 🌍 Internationalization (i18n) Improvements
- **Robust Path Matching**: Replaced unreliable glob matching with a high-performance **Regex-based engine** with caching. Full support for recursive `**` patterns across all Python versions.
- **Config Injection**: Fixed a bug where i18n settings were ignored during result aggregation.
- **CLI Scope Control**: Added `--i18n-scope` to `ai-ctx qgis` command.
- **Improved Reporting**: Enhanced CLI output to show active scope and module coverage.

### 🧪 Quality & Standards
- **Quality Score**: Maintained a record **98.4/100** Quality Score.
- **Test Coverage**: Successfully migrated and verified all tests (270+) using Docker-based CI.
- **ADR 0006**: Formalized the modular architecture and decoupled components.

### 🏎️ Performance & Orchestration
- **Smart Parallelism**: Optimized task batching for concurrent analysis.
- **Incremental Cache**: Refined `mtime` and `size` validation for lightning-fast re-analysis.
- **FastIgnore Engine**: High-performance regex-based file filtering.

### 🚩 Key Fixes
- Fixed `AttributeError` in CLI reporting when metadata was invalid.
- Resolved `KeyError: 'class'` in Decorator detectors.
- Fixed recursive ignore failures in deep directory structures.
- Restored missing facade exports in `fs_utils.py`.
