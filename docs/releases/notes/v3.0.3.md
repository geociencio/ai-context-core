# Release Notes - v3.0.3

## i18n Precision & Heuristic Refinement 🌍

Esta versión se enfoca en mejorar la precisión del análisis de cumplimiento para plugins de QGIS, específicamente en el área de internacionalización (i18n).

### 🚀 Mejoras Principales

#### 1. Soporte Completo para `translate()`
Anteriormente, el analizador solo contaba las llamadas a `self.tr()`. Ahora, se agregan correctamente las llamadas a `QCoreApplication.translate()`, proporcionando una métrica real del esfuerzo de internacionalización del desarrollador.

#### 2. Heurísticas de Precisión Avanzadas
Se han implementado filtros inteligentes para reducir drásticamente los falsos positivos en el conteo de "cadenas totales":
- **Loggers e Informativos**: Las cadenas pasadas a `logger.debug()`, `info()`, etc., ya no se cuentan como translatables.
- **Excepciones Técnicas**: Se ignoran los mensajes de error en `ValueError`, `TypeError` y otras excepciones comunes.
- **Limpieza de Ruido**: Se filtran automáticamente rutas de archivos, URLs, marcadores de posición (`{}`) y cadenas de un solo carácter.

### 🛠 Detalles Técnicos
- Refactorización de `QGISComplianceVisitor` en `ast_qgis.py` para incluir seguimiento de estado en llamadas.
- Actualización de `ResultsAggregator` para la suma multivariable de estadísticas i18n.
- Inclusión de una nueva suite de tests unitarios: `tests/test_qgis_compliance.py`.
