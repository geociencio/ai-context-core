# Release Notes - v3.3.0 (QGIS Edition)

Esta versión introduce capacidades avanzadas de auditoría para plugins de QGIS, enfocándose en la transición hacia QGIS 4.x y Qt6.

## Novedades Principales

### 🗺️ Auditoría de QGIS 4.x (Qt6 Readiness)
- **QGISApiChecker**: Nuevo motor de análisis estático que detecta APIs obsoletas de QGIS 3.x.
- **Detección de Riesgos Qt6**: Identificación proactiva de macros `SIGNAL()` y `SLOT()` que fallarán en Qt6.
- **Mejores Prácticas**: Sugerencias automáticas para usar `QgsSettings` y APIs de vista de capas más robustas.

### 📦 Análisis de Recursos y Metadatos
- **Soporte de plugin.xml**: Parser XML integrado para validar metadatos en formatos legados.
- **Detección de Inconsistencias**: Validación automática de discrepancias de versión/nombre entre `metadata.txt` y `plugin.xml`.
- **Validación de .qrc**: Identificación de archivos de recursos Qt.

### 🐛 Correcciones Críticas
- **Metrics Aggregation**: Se resolvió el bug que causaba que las métricas globales (Funciones, Clases, Complejidad) se reportaran como cero en el archivo `AI_CONTEXT.md`.

## Mejoras Técnicas
- Nueva arquitectura de `QGISBuilder` para reportes automatizados.
- Refactorización del motor de scoring de cumplimiento QGIS.
- Actualización de la suite de pruebas con 11 nuevos tests especializados.
