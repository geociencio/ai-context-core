# Release Notes - v3.3.0 (QGIS Edition)

This version introduces advanced auditing capabilities for QGIS plugins, focusing on the transition towards QGIS 4.x and Qt6.

## Major Changes

### 🗺️ QGIS 4.x Audit (Qt6 Readiness)
- **QGISApiChecker**: New static analysis engine that detects deprecated QGIS 3.x APIs.
- **Qt6 Risk Detection**: Proactive identification of legacy `SIGNAL()` and `SLOT()` macros that will fail in Qt6.
- **Best Practices**: Automatic suggestions for using `QgsSettings` and more robust layer view APIs.

### 📦 Resource and Metadata Analysis
- **plugin.xml Support**: Integrated XML parser to validate metadata in legacy formats.
- **Inconsistency Detection**: Automatic validation of version/name mismatches between `metadata.txt` and `plugin.xml`.
- **.qrc Validation**: Identification of Qt resource files.

### 🐛 Critical Bug Fixes
- **Metrics Aggregation**: Resolved the bug causing project-wide metrics (Functions, Classes, Complexity) to be reported as zero in `AI_CONTEXT.md`.

## Technical Improvements
- New `QGISBuilder` architecture for automated reporting.
- Refactored QGIS standards compliance scoring engine.
- Updated test suite with 11 new specialized tests.
