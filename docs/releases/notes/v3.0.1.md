# Release Notes v3.0.1

**Release Date:** 2026-01-30
**Type:** Patch Release

## 🐛 Bug Fixes

### QGIS Metadata Parsing
- Fixed an issue where the `ai-ctx qgis` command would correctly validate `metadata.txt` but fail to display extracted information (Plugin Name, Version, etc.), showing "N/A" instead.
- Corrected dictionary access pattern in the CLI handler to properly retrieve metadata fields from the nested `content` structure.
- Updated field lookup to use lowercase keys (`qgisminimumversion`) to match `configparser` behavior.
